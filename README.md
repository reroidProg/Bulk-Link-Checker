# Bulk Link Checker

Асинхронный инструмент на Python для массовой проверки ссылок и сохранения результатов в базу данных SQLite.

## Возможности

- Асинхронная проверка HTTP/HTTPS ссылок с помощью библиотеки `httpx`.
- Перехват и обработка ошибок (ошибки HTTP статусов, проблемы с соединением/таймауты).
- Сохранение результатов (URL и код ответа) в базу данных SQLite с помощью `aiosqlite`.
- Простая и понятная структура проекта (всего 79 строк кода на Python).

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта.
2. Установите зависимости (требуются `httpx` и `aiosqlite`):
   ```bash
   pip install httpx aiosqlite
   ```

## Использование

Запустите основной скрипт:
```bash
python3 main.py
```

## Структура проекта

- `checker.py` — класс `UrlChecker` для проверки URL.
- `database.py` — класс `Database` для работы с SQLite.
- `main.py` — точка входа и пример использования.
- `database.db` — файл базы данных (создается автоматически).
